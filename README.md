# YouTube Clone

Projeto de recriação da interface da página inicial do YouTube, desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento Front-end.

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3

## 📌 Funcionalidades e elementos

- Cabeçalho com barra de pesquisa.
- Menu lateral de navegação (Sidebar).
- Categorias de vídeos.
- Grid de vídeos.
- Thumbnails com duração dos vídeos.
- Seção de Shorts.
- Efeitos de hover.
